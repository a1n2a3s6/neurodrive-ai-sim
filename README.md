A **Self-Driving Car Neural Network & Genetic Algorithm Simulator** built completely from scratch in vanilla JavaScript — no external ML libraries. Watch 100 autonomous cars evolve from random crashes into smooth, high-speed racers while inspecting the winning AI's neural network firing in real time.

## Live Demo
👉 **[Launch NeuroDrive AI Live](https://a1n2a3s6.github.io/neurodrive-ai-sim/)**

## Key Features
- **Neural Network from Scratch:** Custom 7 → 8 → 6 → 4 feedforward neural network driven by 7 real-time LiDAR raycast distance sensors.
- **Genetic Evolution Engine:** Automated elitism, crossover, and adjustable mutation rates evolve better drivers every generation.
- **Live Brain Visualizer:** Watch every neuron and weighted synapse of the leading car pulse in real time as it navigates corners.
- **4 Race Circuits:** Test and train AI across Neon Speedway, Tokyo Hairpin GP, Cyber S-Curves, and Apex Pro Circuit.
- **Turbo Training Mode:** Crank simulation speed up to `10x` to evolve dozens of generations in seconds, with a live Fitness Evolution graph.
- **Save & Load Brains:** Persist your best trained neural network in `localStorage` or export/import it as JSON.

## Built With
- HTML5 Canvas 2D
- Vanilla JavaScript (Custom Neural Net, Raycasting & Genetic Algorithm)
- Tailwind CSS (CDN)
